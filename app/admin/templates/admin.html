راهنمای استخراج کوکی‌ها و توکن‌ها

راهنمای گام‌به‌گام و ساده برای استخراج اعتبارنامه‌های Gemini، DeepSeek و ChatGPT

⌨️
کلید میانبر باز کردن منوی ابزار (DevTools):
در ویندوز کلید F12 یا Ctrl + Shift + I را بزنید. (در مک: Cmd + Option + I)
💡 روش جایگزین: راست‌کلیک روی صفحه وب → گزینه Inspect (بازرسی)

🌐 ۱. استخراج کوکی‌های Google Gemini

Google Gemini
  1. وارد سایت gemini.google.com شوید و با اکانت گوگل خود لاگین کنید.
  2. کلید F12 را بزنید تا DevTools باز شود.
  3. از تب‌های بالا وارد Application شوید.
  4. از منوی سمت چپ بخش Storage → Cookies → https://gemini.google.com را انتخاب کنید.
  5. دو کوکی با نام‌های __Secure-1PSID و __Secure-1PSIDTS را پیدا کرده، روی مقدار (Value) آنها دابل‌کلیک و کپی کنید.

🐋 ۲. استخراج توکن DeepSeek (userToken)

DeepSeek V3 / R1
  1. وارد سایت chat.deepseek.com شوید و لاگین کنید.
  2. کلید F12 را بزنید تا پنجره ابزار توسعه‌دهنده باز شود.
  3. وارد تب Application شوید.
  4. از منوی سمت چپ، بخش Local Storage → https://chat.deepseek.com را انتخاب کنید.
  5. کلید userToken (یا در بخش Cookies کوکی با نام userToken) را پیدا کرده و مقدار آن را کپی کنید.

🟢 ۳. استخراج توکن نشست ChatGPT (__Secure-next-auth.session-token)

ChatGPT Web
  1. وارد سایت chatgpt.com شوید و وارد حساب کاربری خود شوید.
  2. کلید F12 را بزنید.
  3. وارد تب Application شده و از ستون سمت چپ به Cookies → https://chatgpt.com بروید.
  4. کوکی __Secure-next-auth.session-token را پیدا کرده و مقدار Value آن را کپی کنید.

🌐 راهنمای انتشار، دیپلوی و میزبانی (Deployment Guide)

آموزش گام‌به‌گام راه‌اندازی OmniBridge روی سرویس‌های ابری رایگان و سرورهای اختصاصی

🎁 ۱. دیپلوی روی سرویس‌های ابری ۱۰۰٪ رایگان (Render & Docker)

☁️ Render.com (پیشنهاد اصلی) رایگان + SSL

بهترین پلتفرم رایگان برای اجرای پروکسی‌های FastAPI.

  1. پروژه را به ریپوزیتوری GitHub خود منتقل کنید.
  2. وارد Render.com شده و یک Web Service بسازید.
  3. در متغیرهای محیطی، ADMIN_USERNAME و ADMIN_PASSWORD را تنظیم کنید.
🐳 Docker و سرور لینوکس (VPS) سرعت بالا

با یک دستور ساده روی هر سرور اوبونتو یا دبیان اجرا کنید:

docker build -t omnibridge .
docker run -d -p 8000:8000 omnibridge
